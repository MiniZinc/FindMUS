======================
# findMUS Changelog #
======================

Recent changes
==============
  - Temporarily added Problem::provedSAT() so the FindMUS tool can distinguish between failing to prove UNSAT and actually proving SAT
  - Added SubsetMap::knownSat(S) which can report whether there is a subset of S that is not blocked with a superset (SAT) block.
  - Added FileSP for reading demos from a file. See the examples/cpp folder for examples.

version 0.5.1
=============
Changes:
  - Added --subsolver and --subsolver-timelimit options due to argument clashing with the main MiniZinc driver


version 0.5.0
=============
Changes:
  - Removed alternative MUS algorithms, Hierarchical MARCO is now the default (and only option)
  - Added restart to flat behaviour which is triggered when the number of satisfiable sets explored in a row is greater than half the number of constraints (this condition is likely to change in future)
  - Added shrink algorithms that use the map (linear with map, quickXplain with map)
  - Added sense option (--paramset hint,mzn,fzn) which sets multiple options at once (default: hint)
  - Removed colour output

Version 0.1.1
=============

Changes:
  - Added --output-json option
